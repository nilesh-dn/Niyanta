# Niyanta

A lightweight, modular **Employee Management System** built with **Core PHP 8+**,
**MySQL/MariaDB**, **Bootstrap 5** and vanilla JavaScript — no frameworks, no
build step, shared-hosting friendly.

> This repository contains the **core platform**: installation wizard,
> authentication & roles, a WordPress-style plugin system, branding & colour
> palettes, dark/light theming, and an extendable dashboard. Real feature
> modules (Employees, Attendance, Payroll, Leave, Notices, …) are added later as
> **plugins** — see [`docs/PLUGINS.md`](docs/PLUGINS.md).

---

## Features

- **Installation wizard** — detects a missing `config.php`, collects database and
  admin details, creates the tables and generates `config.php`, then redirects to
  login. Self-locks once installed.
- **Roles & permissions** — Super Admin › Manager › Employee, plus a
  capability-based permission system that supports **custom roles and permissions
  through plugins** with no core changes.
- **Plugin system** — upload a ZIP, extract, install, activate, deactivate,
  remove. Plugins register routes, menus, permissions and dashboard widgets and
  may run an `install.sql`.
- **Branding** — company name + square logo, three built-in colour palettes,
  unlimited custom palettes, switch the active palette live.
- **Theme** — dark/light toggle in the top-right, remembered per user and across
  logins.
- **Dashboard** — widget registry, extendable by plugins.
- **Security** — PDO prepared statements, output escaping, CSRF on every POST,
  session-fixation protection, validated ZIP extraction.

## Requirements

- PHP 8.0+ with `pdo_mysql` (and `zip` for plugin uploads)
- MySQL 5.7+ / MariaDB 10.3+
- Apache with `mod_rewrite` (an `.htaccess` is included). On Nginx, route all
  requests to `index.php`.

## Installation

1. Upload/clone the project to your web root.
2. Ensure `config.php` does **not** exist and that `storage/`, `uploads/` and the
   project root are writable by the web server.
3. Visit the site in a browser — the **installation wizard** launches
   automatically. Provide database credentials, then company and admin details.
4. You're redirected to the login page. Sign in with the admin account.

### Local development

```bash
php -S localhost:8000          # serve from the project root
# open http://localhost:8000
```

To re-run the installer, delete `config.php`.

## Project structure

```
/core        framework: Router, Auth, Permissions, PluginManager, Hooks, …
/controllers built-in controllers (auth, dashboard, settings, branding, plugins)
/views       layouts, partials and page templates
/install     installation wizard + schema.sql
/plugins     installable plugins (ships with hello-example, deactivated)
/modules     reserved for first-party modules
/assets      core CSS/JS
/themes      theme/style overrides
/uploads     logos, plugin ZIPs, user files (runtime, gitignored)
/storage     logs, cache, sessions (runtime, gitignored)
config.php   generated by the installer (gitignored)
```
